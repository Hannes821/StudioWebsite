## Currently in focus

**Healthbar and selection:** Checking healthbar light emission remains an open task. Custom Depth/Stencil outlines for occluded units and player colours are documented in the task export. [See the working context](healthbar.html).

**Documentation to clarify:** The RVT guide contains UI icon content, and the damage guide gives conflicting descriptions of Piercing. [Review open questions](klaerungen.html).

## Maintain it together

This first edition uses the source snapshot received on **18 September 2026**. Design intentions, documented implementation and verified runtime behaviour are kept distinct. New decisions and document revisions should retain their source and date. [How to contribute](mitarbeiten.html).

Hannes is the repository owner. **Arina / Pcho is Technical Lead**, and **Jonathan von Acker / Gahmuret is Art Lead**. These roles were confirmed by Hannes; repository access is tracked separately from editorial responsibilities.

## Public release

On 26 September 2026, Feldfeste Games approved public access to the complete wiki and all 17 original Operation Instructions to support modding. Historical confidentiality labels in the unchanged PDFs refer to their original internal editions; these documents are now published with the studio’s permission. Public access does not by itself change the licence of the game, code or assets.
