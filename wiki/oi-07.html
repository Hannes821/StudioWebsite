This guide is supposed to be a quick reference for any level designer in our team to build
levels. Just follow the Scheme and you should be fine. As this is a work in progress, details
will be updated and added. For any feedback and questions, please directly target our discord
channel for level design questions!

9. Create Navmesh
Steps to Generate NavMesh
1. Add Volume: Go to the Place Actors panel (Window > Place Actors), search for "Nav
Mesh Bounds Volume", and drag it into the level.
2. Scale Volume: Scale the volume to encompass all areas where AI should walk.
3. Visualize: Press the P key on your keyboard to toggle the green visualization of the
NavMesh.
4. Automatic Build: Unreal automatically generates (bakes) the mesh within this volume
immediately upon adding it.
This video demonstrates how to add and scale a NavMesh Bounds Volume:
ZenvaYouTube• 20.11.2022
Key Configuration Settings (Project Settings > Navigation Mesh)
● Agent Radius/Height: Defines the size of the AI characters.
● Agent Max Slope: Sets the maximum steepness the AI can walk.
● Max Step Height: Dictates the height of obstacles the AI can step over.
● Runtime Generation: Set to "Dynamic" to update the navmesh during gameplay, or
"Static" for bake-only.

You can watch this video to see how to configure the NavMesh settings:
underscoreYouTube• 17.03.2022
Pro Tips
● Dynamic Navigation: For procedural levels, set Runtime Generation to "Dynamic"
and use Navigation Invokers to generate mesh around players only.
● Modifiers: Use Nav Modifier Volumes to mark areas as dangerous or blocked.
● Auto Link Generation: In UE 5.5+, you can enable "generate nav links" in the Recast
NavMesh settings to automatically create jumping/falling links for AI.
