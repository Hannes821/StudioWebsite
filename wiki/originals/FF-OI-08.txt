Avoid Duplicates 
Use data structures instead, like data tables, arrays, maps. Refactoring! 
 
Avoid Super Classes  
Solid, responsible Data. Use inheritance, use components. 
 
Avoid static communication with hard references 
Use Delegates /event Dispatchers if you don’t have to use a hard reference.
