Confidential Operation Instruction

Table of Contents
1. Gain Access
2. Install Plugins
3. Compile Build
4. Start & Test





1. Gain Access
The Development Build is being stored at Github:
https://github.com/Hannes821/Castellum

provide your work email address.
1. Get added by the admin to the repository as collaborator;
2. Clone that build either via “download ZIP” or “clone” to your git desktop or any other
fetching tool you might be familiar with.
3. Check that the entire build was downloaded correctly and “fetch” updates of main
branch.

2. Install Plugins
1. You will need a few plugins which are being used:
• Journeymans Minimap Plugin
• Advanced Sessions
• Steam Advanced sessions
• Others (…)
These are packaged here:
https://drive.google.com/drive/folders/1KQbOhYlPeG2P6dYlMpu5j6sGApIQhB8e

(make sure you have gotten access via work email from admin)
2. Place the plugins under Epic/Unreal/5.2/Plugins (this path needs to be checked)
